# Coin-Flip

# 1-Rupee Decision Toss
Sometimes, the hardest part of the day is just making a choice. This project is a modern, digital take on the classic Indian One Rupee coin toss. Built with a focus on smooth physics and sleek "Glassmorphism" design, it brings a tactile feel to your digital decisions.
# Features
3D Physics Animation: A realistic 1.5-second spin using CSS 3D transforms—no bulky video files or heavy libraries.
Classic Iconography: Features the iconic Lion Capital (Heads) and the bold "1" denomination (Tails) for instant clarity.
Result Ceremony: A clear, animated reveal that tells you exactly what the outcome is so there's no second-guessing.
Smart Button: The interface guides you; once you toss, the button invites you to "Toss Again" with a subtle pulse.
Responsive Design: Works perfectly on your phone, tablet, or desktop.
# Built With
HTML5: Clean, semantic structure.
Modern CSS: Utilizing perspective for 3D effects, backdrop-filter for the frosted glass look, and mesh gradients for a premium background.
Vanilla JavaScript: Lightweight logic to handle the random math and animation states.
How to Use
Open the App: Just open the index.html file in any modern web browser.
The Toss: Click the "TOSS COIN" button.
The Reveal: Watch the coin spin! The result will pop up in a glowing banner once the coin lands.
Repeat: Need a best-of-three? Hit "TOSS AGAIN".
# Why I Built This
This project started as a simple "permission toss" tool. I wanted to take a basic utility and rebuild it using 2026 design standards—moving away from static images and towards a more interactive, fluid experience that feels like a real app.
